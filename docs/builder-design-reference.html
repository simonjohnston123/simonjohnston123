Placid CRM — Website Builder design reference

The full interactive mockup the client supplied on 2026-07-29 is preserved in git history at this path's first commit. Design tokens + spec above. Key decisions the real build follows:

  • Dark chrome (ink-900/800/750), bright WHITE canvas = brightest thing on screen.
  • 5-zone shell: rail 56px · panel 288px · canvas 1fr · inspector 304px; topbar 52px; status bar 30px.
  • Two-signal colour: TEAL #00C7A9 = selected/yours; CORAL #FF5C8A = drop target. Never share meaning.
  • Structure tints: Section #7C9CFF, Row #9B8CFF, Column #63C7F5 (kind dots + breadcrumb).
  • Rail panels: Add elements · Section library · Layers · Pages · Theme & brand · Media · Page settings.
  • Add-elements panel = tile grid grouped Layout / Basic / CRM & Convert, with search.
  • Canvas: device frame + breakpoint switch (1180/768/390); element hover = faint teal outline + mono name badge; selected = solid teal + floating tools (move/duplicate/save-to-library/delete); coral drop-line with "DROP: ROW → COLUMN n"; "Add section" pill between sections.
  • Inspector: kindchip + name; tabs Content / Style / Advanced; box-model spacing editor (margin/padding); responsive visibility chips (DESK/TAB/MOB); desktop-styles-cascade-down model.
  • Status bar: clickable ancestry breadcrumb (Section › Row › Column › Button) + dimensions + autosave + version.
  • Selection rule: innermost element wins (stopPropagation); breadcrumb shows full path.
  • Fonts: Inter Tight (UI), IBM Plex Mono (labels/units/meta).
