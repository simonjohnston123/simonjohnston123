# Mall music

Drop a **licensed** looping track here named exactly:

    mall-loop.mp3

The live shop plays it automatically (looped, low volume) as soon as a visitor
taps into the experience. Until this file exists, a soft generated Web Audio pad
plays instead, so there is always ambience.

Notes:
- Use a track you have rights to loop publicly (royalty-free / licensed). This is
  public-facing, so an unlicensed commercial song would get us in trouble.
- Keep it seamless-looping and mellow (mall background vibe, not a hook).
- MP3 is safest for browser + app support. ~1–3 min loop, <5 MB is ideal.
